# 五年級闖關王（五上 社會康軒＋自然翰林）

給威澈在 iPad 上用的學習遊戲，玩法和「國一闖關王」相同：每天要完成社會和自然兩科，內含講義的重點筆記。
不用上架，不用帳號，進度存在 iPad 本機（和國一闖關王分開存）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面與樣式 |
| `app.js` | 遊戲邏輯；最上面是**任務與獎勵規則**的數字（與國一闖關王同一套程式） |
| `chapters.js` | App 設定、科目、課次、期中／期末範圍、**重點筆記**（整理自「課文重點整理\威澈」的講義） |
| `questions.js` | **題庫** 219 題：社會 10 課＋主題探究 122 題、自然 4 單元 97 題 |
| `sw.js`、`manifest.webmanifest`、`icon-*.png` | 離線快取、主畫面圖示 |

## 題型
- 選擇題（3～4 個選項）
- **是非題**（○ 對／✕ 錯，和學校考卷一樣）
- 排序題（年代、史前文化、彩虹顏色、水分在植物體內的路徑…）

## 範圍
- **期中考**：社會第一、二單元（1-1～2-2）＋自然第 1、2 單元（預設）
- **期末考**：社會第三、四單元＋主題探究＋自然第 3、4 單元
- 家長頁可以一鍵切換，也能逐課勾選。實際範圍以學校公告為準。

## 每日任務與獎勵
和國一闖關王相同：社會挑戰、自然挑戰、讀一篇重點、複習錯題；兩個挑戰都完成才算打卡。
- **每天最多拿 100 金幣**（家長手動加的不算）。
- 獎勵預設價格：多玩 30 分鐘平板 450、點心 350、決定晚餐 600、電影之夜 900、小禮物 1500；**家長頁可以修改**。
- 兌換：孩子「申請兌換」→ 家長在家長頁按「兌換」才扣金幣；家長也能直接點獎勵兌換。

## 加入 iPad 主畫面
用 **Safari** 開啟網址 → 分享 ⬆️ →「加入主畫面」。家長密碼預設 **0000**。

## 新增題目
在 `questions.js` 照格式加。是非題：`t: 'tf', o: TF, a: 0`（0＝對、1＝錯）。
更新後把 `sw.js` 的 `VERSION` 改一下（例如 `g5q-v2`），iPad 才會抓到新版。

## 🐣 小雞養成（pet.js）
- 首頁左上角的小雞點下去就是養成頁；需要照顧時頭像會出現紅色「!」。
- 照顧（每項 20～50 金幣）：普通飼料、營養大餐、特製點心、一起玩球、公園散步、洗香香、一起讀書；每天還能免費摸摸頭 3 次。
- 飽足、心情、清潔每天會自然減少；太餓時成長變慢（不會死掉）。
- 成長階段：破殼小雞 → 毛茸茸小雞 → 活潑小雞 → 少年雞 → 大公雞 → 傳說神雞。
- 小雞商店：顏色、帽子、衣服、裝備、坐騎、背景，小東西 10～50、好的 100～500、最好的 1000 金幣；改名第一次免費、之後 10 金幣。
- 價格都在 pet.js 最上面，可以直接改。
